## Install on Windows or Linux

1. Extract every ZIP into **the same destination folder**. Each ZIP contains a `Yarg songs` folder; their contents merge into one complete library. On Windows, choose the same destination in **Extract All** for each part.
2. Start YARG. Under **Settings → Songs**, add that extracted `Yarg songs` folder to your song folders.
3. Choose **Scan Songs**, then find a song in the library and select Vocals.

The songs are **not bundled with the game build**. Keep the song folder when updating the game; it can be reused without downloading the library again.
Game settings, microphone profiles, and per-song key/vocals/speed presets are stored separately by YARG and are not included in this song-library download.

## What is included

This is a snapshot of the local song library on 16 October 2026: 1,830 files, 6,545,812,135 bytes before ZIP metadata.
It includes the converted song folders, existing stems and charts, and the newly added From Now On autochart and She Used To Be Mine.
The three entries previously flagged for chart/metadata review are retained in the snapshot and may still be rejected by YARG.
Original RB3CON backups and conversion work folders are outside the library and are not included.

The bulk archives are hosted as [release assets](https://github.com/santy81855/YARG/releases/tag/music-library-2026-10-16) because they exceed GitHub's regular Git file limits.
The files in this folder describe and link to that snapshot.

## Verify downloads

Download [SHA256SUMS](https://github.com/santy81855/YARG/releases/download/music-library-2026-10-16/SHA256SUMS) to verify the files.
[library-manifest.json](library-manifest.json) records each source file, its checksum, and which ZIP contains it.
ZIP integrity and upload checksums are verified before this snapshot is published.

Song recordings, artwork, and charts retain their respective ownership and are not covered by the YARG source-code license.
